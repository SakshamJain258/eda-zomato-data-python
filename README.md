# Zomato Restaurant Data Analysis 🍽️

## 📌 Overview
This project performs Exploratory Data Analysis (EDA) on the Zomato restaurant dataset to uncover
patterns related to restaurant ratings, pricing, online ordering, and location-based trends.

## 🧹 Data Cleaning
- Handled missing values 
- Fixed string-converted NaN issues after CSV reload
- Performed log transformations to reduce skewness
- Created weighted ratings based on review counts

## 📊 Exploratory Analysis
- Rating distribution analysis
- Online order vs rating comparison
- Average cost vs rating relationship
- Correlation among numerical features

## 🛠️ Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
